Criptografia (Caesar Cipher) - Projeto para o Code in Place 2025

Script de console em Python para criptografia e descriptografia de mensagens, utilizando a clássica Caesar Cipher como método. Funciona deslocando o posicionamento de cada letra da mensagem por um número fixo de posições no alfabeto.
Projeto Final para o Code in Place 2025, da Stanford University.
